7.1
Introduction
This clause defines the optional support of the NGSI-LD API for sending notifications via the MQTT protocol [24] and
[25]. The subscriptions are handled using the HTTP binding as described in clause 6, but instead of an HTTP endpoint,
an MQTT endpoint is provided.

6.37.3.1
GET
This method is associated to the operation "Retrieve Snapshot Status" and shall exhibit the behaviour defined by
clause 5.16.3. The Snapshot identifier is the value of the resource URI variable "snapshotId". Figure 6.37.3.1-1 shows
the Retrieve Snapshot Status interaction and Table 6.37.3.1-1 describes the request body and possible responses.

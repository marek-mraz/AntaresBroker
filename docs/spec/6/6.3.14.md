6.3.14
Tenant specification
If the system implementing the NGSI-LD API supports multi-tenancy as described in clause 4.14 and clause 5.5.10, the
Tenant, to which the NGSI-LD HTTP operation is targeted, is specified as the HTTP header "NGSILD-Tenant",
whose value is the String identifying the Tenant. In case the target Tenant is the default Tenant, the HTTP header
is omitted. If the HTTP header "NGSILD-Tenant" is present in the HTTP request, it shall also be present in HTTP
response. This also applies to HTTP notifications sent as a result of subscriptions with an "NGSILD-Tenant" HTTP
header (clause 6.3.8).

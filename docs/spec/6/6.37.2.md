6.37.2
Resource definition
Resource URI:
•
/snapshots/{snapshotId}
Resource URI variables for this resource are defined in Table 6.37.2-1.
Table 6.37.2-1: URI variables
Name
Definition
snapshotId
Id (URI) of the Snapshot whose status is to be retrieved or
updated, or the Snapshot to be deleted.

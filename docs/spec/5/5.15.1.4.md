5.15.1.4
Behaviour
•
If the Context Source is unable to supply identity information about itself, then error of type
NotImplemented shall be raised.
•
Return a JSON-LD object representing the identity of the Context Source itself as mandated by clause
5.2.40. This can also include additional configurational data dependent on the specific Context Source
implementation.

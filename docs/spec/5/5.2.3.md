5.2.3
@context
When encoding NGSI-LD Entities, Context Source Registrations, Subscriptions and Notifications, as pure
JSON-LD (MIME type "application/ld+json"), an array (flattened to a single string if necessary), containing
a user @context where present, and the core @context (as described in clause 4.4) shall be included as a special member
of the corresponding JSON-LD Object. Table 5.2.3-1 gives a precise definition of this special member.

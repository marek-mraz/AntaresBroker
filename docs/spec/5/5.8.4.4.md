5.8.4.4
Behaviour
•
The NGSI-LD system shall list all the existing subscriptions up to the limit specified as input data. If no limit
is specified the number of subscriptions retrieved may depend on the implementation.
•
Pagination logic shall be in place as mandated by clause 5.5.9.

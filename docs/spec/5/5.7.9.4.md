5.7.9.4
Behaviour
Return a list of JSON-LD objects representing the details of available attributes as mandated by clause 5.2.28 (restricted
to the elements id, type, attributeName and typeNames) that belong to entity instances existing within the NGSI-LD
system. See clause 5.7.11 for architecture-related implementation aspects, in particular the distributed behaviour.

5.6.7.3
Input data
•
A JSON-LD Array containing one or more JSON-LD documents each one representing an NGSI-LD Entity as
mandated by clause 5.2.4. See clause 5.5.11.1 for information on behaviour when there is more than one
instance of the same entity in the input Array.

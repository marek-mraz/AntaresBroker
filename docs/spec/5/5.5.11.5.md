5.5.11.5
Batch Entity Merge case
The Batch Entity Merge operation has as input an array of Entity IDs, for the entities to be merged. If an Entity ID is
replicated in the array, these merge operations shall be done in chronological order. Only the entity resulting from
merging all of the entity instances, in the correct order, is maintained in the current state (as defined in clause 4.3.1). For
Temporal Evolution of Entities (as defined in clause 4.3.1), all entity instances shall be taken into account,
in the correct order.

4.16
Supporting Multiple Entity Types
From NGSI-LD API version 1.5.1 onwards, multiple Entity Types for any Entity are supported. An Entity is uniquely
identified by its id, so whenever information is provided for an Entity with a given id, it is considered part of the same
Entity, regardless of the Entity Type(s) specified. To avoid unexpected behaviour, Entity Types can be implicitly added
by all operations that update or append attributes. There is no operation to remove Entity Types from an Entity. The
philosophy here is to assume that an Entity always had all Entity Types, but possibly not all Entity Types have
previously been known in the system. The only option to remove an Entity Type is to delete the Entity and re-create it
with the same id. Alternatively, a batch upsert with 'replace' update mode can be used, as described in clause 5.6.8.
